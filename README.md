# Monitoramento do Nível de Água de um Reservatório
### Descrição do projeto

Este projeto foi criado em Python com a finalidade de indicar o nível de água de um reservatório, empregando cores para tornar mais fácil a identificação do estado.

O programa pede ao usuário para fornecer um número entre 1 e 5 e exibe uma mensagem mostrando o nível de água correspondente.

A biblioteca Colorama foi empregada para aprimorar a visualização, possibilitando a exibição de textos coloridos no terminal.

###  Objetivo

Praticar os conhecimentos adquiridos em programação Python, principalmente:

Entrada de dados com input();

Conversão de valores utilizando int();

Estruturas condicionais if, elif e else;

Utilização da biblioteca externa colorama;

Exibição de mensagens coloridas no terminal;

Validação de valores informados pelo usuário.

### Funcionamento

O programa utiliza uma estrutura de decisão para verificar o número informado pelo usuário.

Cada condição representa um nível diferente do reservatório:

if verifica o nível 1;

elif verifica os níveis de 2 a 5;

else identifica valores fora do intervalo;

Fore define a cor das mensagens;

Style.RESET_ALL restaura a formatação original do terminal.
